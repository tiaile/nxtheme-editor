# nxtheme-editor

A modern, standalone web-based editor for Nintendo Switch custom home menu themes (`.nxtheme` files). 

This editor is built using **Nuxt 4**, **Una UI**, **UnoCSS**, and is powered by the **[@themezernx/nxtheme-builder](https://www.npmjs.com/package/@themezernx/nxtheme-builder)** package.

## Features

- **Visual Theme Editing**: Edit layouts, backgrounds, colors, and metadata for custom home menu themes.
- **Modern UI Components**: Sleek interface built with Una UI component library.
- **Fast Building**: Responsive development experience using Vite and UnoCSS.
- **Zero-Dependency Core Parsing**: Theme files compiled and parsed on top of `@themezernx/nxtheme-builder`.

## Getting Started

### Prerequisites

Make sure you have [Bun](https://bun.sh) installed on your machine.

### Installation

Clone the repository and install the dependencies:

```bash
git clone https://github.com/tiaile/nxtheme-editor
bun install
```

### Development Server

Start the local development server with hot module replacement (HMR):

```bash
bun run start:dev
```

Open your browser and navigate to the local URL (usually `http://localhost:3000`).

### Production Build

To compile a highly optimized production bundle:

```bash
bun run build
```

To preview the built production app locally:

```bash
bun run start
```

## Offline Deployment & Maintenance

The app is a pure client-side SPA (`ssr: false`) — no remote API calls at runtime, so it works fully offline once built.

### One-click offline launch (Windows)

```bat
start-offline.cmd
```

Double-click the script: it starts the production server on `http://localhost:3000` and opens your browser automatically. Requires [Node.js](https://nodejs.org) `>=24` installed (no internet needed at runtime).

### Offline single-file build (`dist-offline/`)

Run `npm run build:offline` to produce a portable, readable offline package in `dist-offline/`:

```
dist-offline/
├── index.html        ← 所有 JS 内联（未压缩，可读可改），双击即可打开
├── style.css         ← CSS 独立文件（相对路径引用，file:// 下正常加载）
├── applets/          ← 预设图标
└── themezer-icon.png ← 页脚 Logo
```

Copy/move the **whole folder** together and double-click `index.html`. Works offline from any location (no server, no internet). JS must stay inlined because browsers block external ES modules on `file://`.

### Rebuilding after source changes

```bash
npm run build:offline
```

It re-generates the static build and re-inlines it into `dist-offline/`. Only edit the **source files** (`pages/`, `composables/`, `types/`, ...); `dist-offline/` is a build artifact and gets overwritten each time.

### Notes

- Dependencies are only needed at build time. After `npm run build`, `.output/` is self-contained.
- `nuxt.config.ts` uses `vite.build.cssMinify: "esbuild"` because the default `lightningcss` minifier rejects a CSS rule generated by Una UI (`::file-selector-button:target`); esbuild parses it leniently and browsers safely ignore the rule.
- The local proxy in `.npmrc` (`127.0.0.1:10808`) is only used when running `npm install`; it is not needed to run the built app.
